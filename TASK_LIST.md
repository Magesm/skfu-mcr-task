# Список заданий

1. **`task/01`** — Сайт-анкета на свободную тему: сверстать страницу с формой.
 *Технологии:* HTML, CSS

2. **`task/HC-04`** — Игра по CSS: Flexbox Froggy, практика `flexbox`.
 *Технологии:* CSS (flexbox)

3. **`task/JS-01`** — Задачи по JavaScript для знакомства с языком.
 *Технологии:* JavaScript, Node.js

4. **`task/TS-02`** — Упражнения по TypeScript: интерфейсы, union/narrowing, дженерики, классы.
 *Технологии:* TypeScript, `tsc`, Node.js

5. **`task/CAT-01`**, **`task/CAT-01-demo`** — Асинхронная загрузка данных из публичного API и минимальный UI.
 *Технологии:* TypeScript, esbuild, `fetch`/`async-await`, npm, Node.js

6. **`task/EXPO-00`** — Знакомство с Expo: подготовка окружения для React Native.
 *Технологии:* React Native, Expo

7. **`task/EXPO-01`** — Туториал Expo, часть 1: создание приложения, навигация и первый экран (главы 1–3).
 *Технологии:* React Native, Expo, Expo Router, TypeScript

8. **`task/EXPO-02`** — Туториал Expo, часть 2: выбор изображения, модальное окно и жесты (главы 4–6).
 *Технологии:* React Native, Expo, `expo-image-picker`, Expo UI, Reanimated

9. **`task/EXPO-03`** — Туториал Expo, часть 3: снимок экрана, статус-бар, сплэш-экран и иконка (главы 7–8).
 *Технологии:* React Native, Expo, `expo-media-library`, `react-native-view-shot`

10. **`task/EXPO-04`** — Перенос приложения «Мой IP» из CAT-01 на React Native с Expo.
 *Технологии:* React Native, Expo, TypeScript, `fetch`

> Ветки `*-demo` — это готовые шаблоны-заготовки для соответствующих заданий.

> При сдаче задания в описании Pull Request укажите: `name: [NAME] [SURNAME]; group: [GROUP]`. Подробнее — в разделе **Pull Request** файла [README.md](README.md).
